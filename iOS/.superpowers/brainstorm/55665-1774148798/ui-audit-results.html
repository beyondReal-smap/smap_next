SMAP iOS UI/UX 감사 결과

현재 코드에서 발견된 개선 포인트를 우선순위별로 정리했습니다. 집중할 영역을 선택해주세요.

A

디자인 시스템 통합 CRITICAL

214개 하드코딩된 Color(red:...) → SMAPTheme.Color 전환

SMAPButton, SMAPTextField, SMAPLoadingView 등 이미 만들어진 컴포넌트가 0곳에서 사용 중

영향: 26개 파일 | 효과: 디자인 일관성, 다크모드 준비, 유지보수성

B

Deprecated API 제거 HIGH

NavigationView → NavigationStack (7개 파일)

.edgesIgnoringSafeArea → .ignoresSafeArea (37곳)

.navigationBarHidden → .toolbar(.hidden) (18곳)

영향: iOS 17+ 최적화, Xcode 경고 제거

C

접근성 (Accessibility) CRITICAL

accessibilityLabel/Hint 사용: 0건

모든 버튼, 아이콘, 인터랙티브 요소에 스크린 리더 지원 없음

영향: 전체 앱 | 효과: App Store 심사, 법적 요건, 사용자 경험

D

모던 SwiftUI 패턴 도입 MEDIUM

.refreshable 풀투리프레시 (1곳만 사용 중 → 전체 리스트)

.task {} 비동기 로딩 (.onAppear + Task 대체)

@FocusState 키보드 관리 (1곳만 사용 중)

영향: 주요 화면 | 효과: UX 개선, 코드 간결화

E

로딩/에러/빈상태 표준화 LOW

로딩 상태: 각 화면마다 다른 ProgressView 스타일

에러 표시: Alert API 구/신 혼용

빈 상태: 일부 화면만 구현

영향: 전체 앱 | 효과: 일관된 사용자 경험
